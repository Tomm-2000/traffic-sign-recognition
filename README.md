# Traffic Sign Recognition

Put your own sign images inside inputs/. The notebook downloads bazyl/gtsrb-model and reports the predicted labels and confidence scores. It uses pretrained inference. See DATASET.md for the dataset overview.

Notebooks: [traffic-sign-recognition.ipynb](traffic-sign-recognition.ipynb)

From this directory, use a fresh Python 3.11 environment:

```bash
python -m pip install -r requirements.txt
python -m jupyterlab
```
